# crit-announcer
This module is a small hello-world type project to play around a bit with FoundryVTT.  
The goal was to have custom sound effects for DnD5e games when players get a critical success or failure on an attack roll or death save.

## Compatibility
This module is designed to be used with the DnD5e system.  
As this is a beginner project, I have not tested compatibility with any other modules so far.

## Settings
![alt text](settings.png)

1. You can toggle the announcement of attack rolls and death saves independently from one another.
2. You can choose a different sound for any of the possible announcements by selecting a sound file.
